# UI 设计语言规范

> 目标读者：执行前端实现的 AI Agent。
> 本文档定义项目的视觉系统，所有组件和页面必须遵循此规范。
> 设计哲学：Apple 的系统化精致 + Claude 的暖色人文克制。

---

## 1. 设计哲学

**核心原则：**
- 暖色调、低装饰、高留白
- 内容优先，界面服务于内容
- 功能性动效，不做装饰性动画
- 无阴影层级，用边框和背景色差区分

**融合公式：**
```
视觉温度 = Claude（暖色调）
间距网格 = Apple（4px 基础网格，兼容 8pt 倍数）
圆角     = Apple（标准 border-radius，10-16px 范围）
阴影     = Claude（无阴影，纯边框/背景色差）
动效     = Apple 缓动曲线 + Claude 克制度
暗色模式 = Apple 策略 + Claude 暖色倾向
信息密度 = Landing 低密度 / 功能区中密度
```

## 3. 字体系统

### 3.1 字体选择

| 用途            | 字体                | 回退                    |
| --------------- | ------------------- | ----------------------- |
| 标题（Display） | `Plus Jakarta Sans` | `system-ui, sans-serif` |
| 正文（Body）    | `Plus Jakarta Sans` | `system-ui, sans-serif` |
| 等宽（Code）    | `JetBrains Mono`    | `Consolas, monospace`   |

**为什么选 Plus Jakarta Sans：** 几何无衬线体，字形圆润但不幼稚，兼具 Apple SF Pro 的精致感和 Claude 的温暖气质。免费开源（Google Fonts），中文回退系统字体。

### 3.2 字号层级

| 层级    | 字号 | 字重 | 行高 | 用途                |
| ------- | ---- | ---- | ---- | ------------------- |
| Display | 36px | 700  | 1.1  | Landing Page 主标题 |
| H1      | 28px | 600  | 1.2  | 页面标题            |
| H2      | 22px | 600  | 1.3  | 区块标题            |
| H3      | 18px | 600  | 1.4  | 卡片标题、Tab 标题  |
| Body    | 15px | 400  | 1.6  | 正文、表单标签      |
| Body-sm | 13px | 400  | 1.5  | 辅助说明、时间戳    |
| Caption | 12px | 400  | 1.4  | 标签、badge 文字    |
| Code    | 14px | 400  | 1.5  | 代码块、JD 原文     |

### 3.3 排版规则

- 标题使用负字间距：Display `-0.02em`，H1 `-0.015em`
- 正文默认字间距
- 中英文混排：中英文之间自动加 `0.25em` 间距（CSS `word-spacing` 或前端处理）
- 数字使用等宽数字特性（`font-variant-numeric: tabular-nums`）

## 6. 组件规范

### 6.1 按钮

| 类型       | 背景      | 文字      | 边框                | Hover                       |
| ---------- | --------- | --------- | ------------------- | --------------------------- |
| 主按钮     | `#1A1A1A` | `#FFFFFF` | 无                  | `#333333`                   |
| 次要按钮   | 透明      | `#C8553A` | `1px solid #C8553A` | 背景 `rgba(200,85,58,0.06)` |
| Ghost 按钮 | 透明      | `#6B6560` | 无                  | 背景 `rgba(0,0,0,0.04)`     |
| 禁用态     | `#E8E4DD` | `#9C9690` | 无                  | 无变化，cursor: not-allowed |

按钮高度：36px（默认）、32px（紧凑）、40px（大）
内边距：`8px 16px`（默认）

### 6.2 输入框 / Textarea

| 状态     | 边框      | 背景      | 说明                    |
| -------- | --------- | --------- | ----------------------- |
| Default  | `#E8E4DD` | `#FFFFFF` | —                       |
| Focus    | `#1A1A1A` | `#FFFFFF` | 边框变深，无 box-shadow |
| Error    | `#C53030` | `#FFFFFF` | 红色边框                |
| Disabled | `#E8E4DD` | `#F3F2EE` | 灰色背景                |

- Placeholder 颜色：`#9C9690`
- 标签位于输入框上方，间距 `space-2`（8px）
- Textarea 最小高度：120px

### 6.3 聊天气泡

| 角色              | 对齐   | 背景色（亮） | 背景色（暗） | 最大宽度 |
| ----------------- | ------ | ------------ | ------------ | -------- |
| 系统（题目/追问） | 左对齐 | `#F3F2EE`    | `#242320`    | 80%      |
| 用户（回答）      | 右对齐 | `#E8E1D8`    | `#3D3A35`    | 80%      |

- 气泡圆角：16px
- 气泡内边距：`12px 16px`
- 消息间距：`space-3`（12px）
- 发送者标识：气泡上方，Caption 字号，颜色为文字-次

### 6.4 卡片

- 背景：`#FFFFFF`（亮）/ `#242320`（暗）
- 边框：`1px solid` 边框色
- 圆角：14px
- 内边距：`space-5`（20px）
- 无阴影

### 6.5 标签页（Tabs）

- 选中态：文字色为主色，下方 2px 实线指示器（颜色 `#1A1A1A`）
- 未选中：文字色为文字-次
- Tab 间距：`space-6`（24px）
- 切换动效：指示器滑动 200ms ease-out

### 6.6 侧边栏导航项

- 高度：36px
- 内边距：`8px 12px`
- 选中态：背景 `rgba(0,0,0,0.06)`（亮）/ `rgba(255,255,255,0.08)`（暗），圆角 8px
- Hover：背景 `rgba(0,0,0,0.03)`（亮）/ `rgba(255,255,255,0.04)`（暗）
- 图标（Lucide）：18px，与文字间距 `space-2`（8px）
- 分隔线：`1px solid` 边框色，上下 margin `space-3`（12px）

### 6.7 骨架屏 + 脉冲进度条

**脉冲进度条：**
- 位置：卡片顶部，高度 2px
- 颜色：强调色 `#C8553A`
- 动画：从左到右无限循环滑动，宽度 40%，duration 1.5s

**骨架屏：**
- 占位块颜色：`#E8E4DD`（亮）/ `#3D3A35`（暗）
- Shimmer 动画：从左到右的高光扫过，duration 1.5s，infinite
- 占位块圆角：4px

### 6.8 Toast 通知

- 位置：右上角，距顶部 16px，距右侧 16px
- 最大宽度：360px
- 圆角：10px
- 背景：卡片背景色 + 左侧 3px 语义色条
- 自动消失：4 秒
- 进入动效：从右侧滑入 + fade，200ms

### 6.9 Mock 模式提示条

- 位置：页面最顶部，全宽
- 高度：32px
- 背景：`#FEF3CD`（亮）/ `#3D3520`（暗）
- 文字：`#856404`（亮）/ `#E0C060`（暗），Caption 字号
- 内容居中："当前为演示模式（后端未连接）"

> Mock 触发逻辑与各功能降级行为见 `FRONTEND_REQUIREMENTS.md` §5.6。

## 7. 动效规范

### 7.1 全局默认

| 属性            | 值                                   |
| --------------- | ------------------------------------ |
| 默认 duration   | 200ms                                |
| 默认 easing     | `cubic-bezier(0.25, 0.1, 0.25, 1.0)` |
| 长动效 duration | 350ms（页面切换、模态框）            |
| 弹性动效        | 不使用                               |

### 7.2 具体场景

| 场景           | 动效                           | Duration | Easing   |
| -------------- | ------------------------------ | -------- | -------- |
| 页面路由切换   | fade（opacity 0→1）            | 200ms    | ease-out |
| 按钮 hover     | 背景色过渡                     | 150ms    | ease     |
| 输入框 focus   | 边框色过渡                     | 150ms    | ease     |
| Toast 进入     | translateX(100%) → 0 + opacity | 200ms    | ease-out |
| Toast 退出     | opacity → 0                    | 150ms    | ease-in  |
| Tab 指示器滑动 | translateX                     | 200ms    | ease-out |
| 骨架屏 shimmer | background-position 循环       | 1.5s     | linear   |
| 打字机光标闪烁 | opacity 0↔1                    | 800ms    | step-end |
| 侧边栏项 hover | 背景色过渡                     | 100ms    | ease     |

### 7.3 禁止事项

- 不使用弹性/弹跳动效
- 不使用 3D 变换
- 不使用滚动视差
- 不使用装饰性入场动画（内容直接出现或 fade）
- 尊重 `prefers-reduced-motion`：减少动效时所有 transition 设为 0ms

## 9. 特殊页面规范

### 9.1 Landing Page

- 信息密度：低（一屏一焦点）
- 最大宽度：1080px，居中
- Hero 区域：项目名 + 一句话定位 + "试一试"按钮
- 技术栈：分组卡片（后端框架 / 数据层 / AI 能力 / 部署），每组一个小卡片内含技术标签
- 暗色模式切换按钮在右上角

### 9.2 功能区通用布局

```

│ [Mock 提示条 - 仅后端不可用时显示]               │
├──────────┬──────────────────────────────────────┤

│ 侧边栏   │        内容区（max-width 720px）      │
│ 220px    │        水平居中                       │
│ 微深背景  │                                      │
│          │                                      │

```

### 9.3 面试聊天页面

- 聊天区占满内容区高度（`flex: 1`，`overflow-y: auto`）
- 配置面板在顶部，面试开始后折叠（高度过渡 350ms）
- 输入框固定在底部
- 消息列表自动滚动到底部
- 面试结束后输入框 disabled，显示"获取评估"按钮

### 9.4 面试评估报告

- 顶部：大数字总分（Display 字号）+ 环形图
- 中部：强项/改进项分栏卡片
- 底部：逐题详情，默认折叠，点击展开（手风琴）
- 环形图配色：总分环用强调色 `#C8553A`（亮）/ `#DA7756`（暗），背景轨道用边框色；逐题分数条用语义色（≥7 Success，5-6 Warning，<5 Error）

### 9.5 简历优化对比

- 左右并排（各 50% 宽度）
- 左侧标题"原文"，右侧标题"优化后"
- 差异处用半透明暖色背景高亮：`rgba(200, 85, 58, 0.12)`

### 9.6 知识库流式输出

- 文本逐字追加渲染
- 末尾闪烁竖线光标 `|`（opacity 动画 800ms step-end）
- 流结束后光标消失
- 完成后文本可选中复制

## 10. 空状态与引导

每个功能页面在用户未操作时显示：

- 一句简短说明（Body 字号，文字-次颜色）
- 一个"试试这个示例"按钮（Ghost 按钮样式）
- 点击后自动填充 textarea 并可直接提交

不使用插图，保持极简。

## 11. 错误处理视觉

### 11.1 Toast（可恢复错误）

- 网络超时、请求失败等
- 右上角弹出，4 秒后自动消失
- 左侧 Error 语义色条

### 11.2 内联提示（不可恢复错误）

- Session 过期、文件格式不支持等
- 在触发位置显示提示条
- 背景：Error 语义色 10% 透明度
- 需用户手动关闭或执行操作（如"重新开始面试"）

---

## 12. 无障碍基线

- 文字/背景对比度 ≥ 4.5:1（WCAG AA）
- 所有交互元素可键盘聚焦
- Focus 态有可见指示（边框变深）
- 按钮和链接有明确的 hover/active 反馈
- 图标配合文字使用，不单独承载含义

---

## 13. 响应式策略

本项目面向桌面端演示，不要求完整移动端适配。但需处理窄窗口场景：

| 断点           | 行为                                        |
| -------------- | ------------------------------------------- |
| ≥ 1024px       | 正常布局：侧边栏 220px + 内容区             |
| 768px ~ 1023px | 侧边栏收起为图标模式（宽 56px），hover 展开 |
| < 768px        | 不做适配（可接受布局溢出）                  |

## 18. 字体加载策略

```css
@font-face {
  font-family: 'Plus Jakarta Sans';
```

- JetBrains Mono 延迟加载（代码块不在首屏关键路径）
- 中文回退 `system-ui`，不额外加载中文字体
