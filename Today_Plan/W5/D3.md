## 学习内容（~30 分钟）

### SQLAlchemy 多数据库

SQLAlchemy 的 `create_engine(url)` 根据 URL scheme 自动选择方言：
- `sqlite:///./job_copilot.db` → SQLite
- `postgresql://user:pass@host:5432/db` → PostgreSQL

代码层面几乎不需要改动，只要 URL 正确 + 安装对应驱动。

### SQLite vs PostgreSQL 差异

| 差异点 | SQLite | PostgreSQL |
|---|---|---|
| JSON 字段 | 存为 TEXT | 原生 JSONB，支持索引 |
| 并发写入 | 单写者锁 | MVCC，支持高并发 |
| 连接方式 | 文件路径 | TCP 网络连接 |
| Alembic 迁移 | 部分 ALTER TABLE 不支持 | 完整 DDL 支持 |

### psycopg2 vs psycopg2-binary

- `psycopg2`：需要编译，依赖 `libpq-dev`
- `psycopg2-binary`：预编译，开发方便但官方不推荐生产用
- 本项目：Dockerfile 里装了 `libpq-dev`，requirements.txt 用 `psycopg2-binary`（简化构建）

## 编码任务

### 任务 1：安装 PostgreSQL 驱动

```bash
pip install psycopg2-binary
```

更新 `requirements.txt` 添加 `psycopg2-binary>=2.9`。

### 任务 2：确认 connection.py 兼容性

检查 `app/database/connection.py`：
- `DATABASE_URL` 已从环境变量读取 → 无需改动
- 如果有 SQLite 特有配置（如 `check_same_thread`），需要条件判断：

```python
connect_args = {}
if DATABASE_URL.startswith("sqlite"):
    connect_args["check_same_thread"] = False

engine = create_engine(DATABASE_URL, echo=False, connect_args=connect_args)
```

### 任务 3：更新 Alembic 配置

检查 `alembic/env.py`：
- 确认 `sqlalchemy.url` 从环境变量读取（不是硬编码 SQLite 路径）
- 如果硬编码了，改为：

```python
from app.database.connection import DATABASE_URL
config.set_main_option("sqlalchemy.url", DATABASE_URL)
```

### 任务 4：容器内执行迁移

```powershell
# 确保容器运行
docker compose up -d

# 在 api 容器内执行迁移
docker compose exec api alembic upgrade head

# 验证表已创建
docker compose exec postgres psql -U postgres -d job_copilot -c "\dt"
```

### 任务 5：验证本地开发仍可用

确保本地（SQLite 模式）不受影响：

```powershell
# 本地环境变量仍为 sqlite
pytest tests/test_database.py -v
```
