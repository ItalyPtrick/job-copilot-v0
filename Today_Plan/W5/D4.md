## 学习内容（~30 分钟）

### 开发 vs 生产环境

| 场景 | 配置 | 说明 |
|---|---|---|
| 生产/演示 | `docker compose up -d` | 全部容器化，一键启动 |
| 开发 | `docker compose -f docker-compose.dev.yml up -d` | 只启动 PG + Redis，应用本地跑 |

开发环境只容器化基础设施（数据库、Redis），应用本地运行方便调试（热重载、断点）。

### Makefile 模式

用 Makefile 封装常用命令，降低记忆负担：

```makefile
up:
    docker compose up -d
down:
    docker compose down
dev:
    docker compose -f docker-compose.dev.yml up -d
test:
    docker compose exec api pytest tests/ -v
```

Windows 下需要安装 `make`（通过 choco 或 scoop），或者用 PowerShell 脚本替代。

## 编码任务

### 任务 1：创建 docker-compose.dev.yml（Doc 06 Step 4）

只包含 postgres + redis，供本地开发使用：

```yaml
version: "3.8"

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: job_copilot
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    ports:
      - "5432:5432"
    volumes:
      - pg_data_dev:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

volumes:
  pg_data_dev:
```

### 任务 2：创建 .env.example

将所有环境变量整理为模板文件（不含真实密钥）：

```env
# LLM
OPENAI_API_KEY=your-key-here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# Embedding
OPENAI_EMBEDDING_API_KEY=your-key-here
OPENAI_EMBEDDING_BASE_URL=https://api.openai.com/v1
OPENAI_EMBEDDING_MODEL=text-embedding-3-small

# Database（本地开发用 SQLite，Docker 部署用 PostgreSQL）
DATABASE_URL=sqlite:///./job_copilot.db
# DATABASE_URL=postgresql://postgres:postgres@localhost:5432/job_copilot

# Redis
REDIS_URL=redis://localhost:6379/0

# Celery
CELERY_BROKER_URL=redis://localhost:6379/1
```

### 任务 3：整理运维命令（Doc 06 Step 5）

在 README.md 中新增「Docker 部署」章节，或创建 `Makefile`：

```makefile
.PHONY: up down dev logs test migrate build clean

up:
	docker compose up -d

down:
	docker compose down

dev:
	docker compose -f docker-compose.dev.yml up -d

logs:
	docker compose logs -f

test:
	docker compose exec api pytest tests/ -v

migrate:
	docker compose exec api alembic upgrade head

build:
	docker compose build --no-cache

clean:
	docker compose down -v
```

### 任务 4：验证开发环境工作流

```powershell
# 启动开发依赖
docker compose -f docker-compose.dev.yml up -d

# 修改本地 .env 的 DATABASE_URL 为 postgresql://postgres:postgres@localhost:5432/job_copilot

# 本地执行迁移
alembic upgrade head

# 本地启动应用
uvicorn app.main:app --reload

# 验证连接
curl http://localhost:8000/
```

## 验收标准

- [ ] `docker-compose.dev.yml` 存在且只包含 postgres + redis
- [ ] `docker compose -f docker-compose.dev.yml up -d` 启动成功
- [ ] `.env.example` 存在且包含所有环境变量（无真实密钥）
- [ ] 本地 `uvicorn` 能连接容器内 PostgreSQL（`DATABASE_URL` 切换后正常工作）
- [ ] `Makefile` 或 README 中有完整运维命令列表
- [ ] `docker compose -f docker-compose.dev.yml down` 清理成功
