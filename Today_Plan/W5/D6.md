## 学习内容（~30 分钟）

### 容器健康检查

Docker Compose 的 `healthcheck` 决定服务是否"就绪"。根路径 `/` 只验证进程存活，`/health` 验证依赖组件（PG、Redis）连通性，让 Compose 知道服务真正可用。

```yaml
healthcheck:
  test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
  interval: 10s
  timeout: 5s
  retries: 3
  start_period: 15s
```

### Multi-stage build

单阶段镜像包含 gcc、make 等构建工具，multi-stage 把构建和运行分离：

- **Stage 1 (builder)**：安装 pip 依赖（含编译工具）
- **Stage 2 (runtime)**：`COPY --from=builder /usr/local /usr/local`，只复制已安装的包

最终镜像不含构建产物，体积更小。

### uv 包管理器

Rust 写的 pip 替代品，依赖解析快 10~50 倍。pip 要几分钟的解析，uv 几秒完成。

## 编码任务

### 任务 1：`/health` 端点

`app/main.py` 新增 `GET /health`：
- PG 检测：`engine.connect()` + `SELECT 1`
- Redis 检测：`redis_client.ping()`（带 `socket_timeout=3` 防挂起）
- 全部正常 → 200 + `{"status":"healthy","postgres":"ok","redis":"ok"}`
- 任一异常 → 503 + `{"status":"unhealthy",...}`

`app/cache/redis_client.py` 添加 `socket_timeout=3`。

### 任务 2：更新 docker-compose.yml healthcheck

将 api 服务的 healthcheck 从根路径改为 `/health`。

### 任务 3：Dockerfile multi-stage + uv

```dockerfile
# Stage 1: builder
FROM python:3.11-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN --mount=type=cache,target=/root/.cache/uv \
    pip install uv && uv pip install --system -r requirements.txt

# Stage 2: runtime
FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /usr/local /usr/local
# ... 非特权用户、gosu、entrypoint
```

### 任务 4：验证

```powershell
docker compose build --no-cache api
docker compose up -d
curl http://localhost:8000/health
docker compose exec api python -m pytest tests/ -v
```

## 踩坑记录

### `docker build -t` 与 `docker compose up` 镜像不一致

`docker build -t job-copilot .` 创建镜像 tag `job-copilot:latest`，但 `docker compose up -d` 使用自动命名的 `job-copilot-v0-api:latest`。两者是不同镜像，导致手动 build 的代码永远进不了 compose 容器。

**解法**：始终用 `docker compose build` 构建，不手动 `docker build -t`。

### Redis 客户端无 socket_timeout 导致健康检查挂起

`redis.from_url()` 默认无 socket 超时，`ping()` 在 Redis 未就绪时无限阻塞，导致 `/health` 返回空响应（连接被关闭）。

**解法**：`redis.from_url(REDIS_URL, decode_responses=True, socket_timeout=3)`。
