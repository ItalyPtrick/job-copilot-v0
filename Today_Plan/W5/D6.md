## 学习内容（~30 分钟）

### Streamlit 多页面

Streamlit 1.10+ 支持 `pages/` 目录约定：

```
ui/
├── app.py              # 主页（入口）
└── pages/
    ├── 1_RAG_问答.py
    ├── 2_模拟面试.py
    └── 3_简历分析.py
```

- 文件名前缀数字控制侧边栏排序
- 每个页面是独立的 .py 文件，自动出现在侧边栏导航
- `st.session_state` 跨页面共享状态

### 与后端 API 交互

页面通过 `requests` 库调用本地 FastAPI：

```python
import requests

API_BASE = "http://localhost:8000"

resp = requests.post(f"{API_BASE}/kb/query", json={"question": user_input})
```

## 编码任务

### 任务 1：重构 ui/ 目录结构

```
ui/
├── app.py              # 主页：项目介绍 + 功能导航
├── pages/
│   ├── 1_RAG_问答.py   # 知识库问答
│   ├── 2_模拟面试.py   # 模拟面试交互
│   └── 3_简历分析.py   # 简历上传 + 分析结果
└── minimal_app.py      # 保留旧版（不删除）
```

### 任务 2：主页 app.py

```python
import streamlit as st

st.set_page_config(page_title="Job Copilot", page_icon="🎯", layout="wide")

st.title("Job Copilot - 求职 AI 助手")
st.markdown("""
### 功能模块
- **RAG 问答**：上传文档，智能问答
- **模拟面试**：AI 面试官，多轮追问
- **简历分析**：上传简历，获取分析报告

👈 从左侧导航选择功能
""")
```

### 任务 3：RAG 问答页

`pages/1_RAG_问答.py` 核心功能：
- 文本输入框：用户提问
- 调用 `POST /kb/query`
- 显示回答 + 来源文档
- （可选）文件上传调用 `POST /kb/upload`

### 任务 4：模拟面试页

`pages/2_模拟面试.py` 核心功能：
- 选择 Skill（下拉框）
- 点击"开始面试"→ 调用 `POST /interview/start`
- 对话式交互：显示题目 → 用户输入回答 → 调用 `POST /interview/answer` → 显示追问或下一题
- 用 `st.session_state` 保存 session_id 和对话历史
- "结束面试"按钮 → 调用 `POST /interview/evaluate` → 显示评分报告

### 任务 5：简历分析页

`pages/3_简历分析.py` 核心功能：
- 文件上传组件（`st.file_uploader`，支持 PDF/DOCX/TXT）
- 可选输入：目标岗位
- 上传后调用 `POST /resume/upload`
- 轮询 `GET /resume/{id}/status` 直到 completed
- 显示分析结果（评分、亮点、不足、建议）
- "导出 PDF"按钮 → 调用 `GET /resume/{id}/export` → 提供下载

### 任务 6：验证

```powershell
# 确保后端运行
uvicorn app.main:app --reload

# 启动 Streamlit
streamlit run ui/app.py
```

在浏览器中逐一测试三个页面的核心流程。

## 验收标准

- [ ] `streamlit run ui/app.py` 启动成功，侧边栏显示 3 个功能页面
- [ ] RAG 问答页：输入问题 → 返回回答（后端需有已上传文档）
- [ ] 模拟面试页：开始 → 回答 → 追问/下一题 → 评估，全流程可走通
- [ ] 简历分析页：上传文件 → 显示分析结果（需要 Celery Worker 运行）
- [ ] 页面间切换不丢失状态（session_state 正常工作）
- [ ] 无 Python 报错（Streamlit 页面不显示红色 traceback）
